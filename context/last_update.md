
`stripe` is the marketplace identifier for Stripe's "Stripe Merchant" plugin ([cursor.com/marketplace/stripe](https://cursor.com/marketplace/stripe)), sourced from [stripe/ai @ plugins/agent-plugin](https://github.com/stripe/ai/tree/plugins/agent-plugin) (v0.5.19). `cursor-public` is the official marketplace ID (it matches your existing plugin cache at `~/.cursor/plugins/cache/cursor-public/`).

## One step you need to do

Run **Developer: Reload Window** (`Cmd+Shift+P`). Cursor only picks up `.cursor/settings.json` plugin entries on reload. After that, "Stripe" should appear under Customize → Plugins, and `~/.cursor/plugins/cache/cursor-public/stripe/` will be populated.

## Notes

- I chose project scope because this repo already commits its `.cursor/` config and the project is Stripe-centric. The sync hook will commit the file at the end of this turn. If you'd rather have it user-wide, use Customize → search "Stripe" → Install → User.
